# Mohamad Ali - Personal E-Portfolio

This repository contains the source code for my dual-identity personal e-portfolio. It serves as both a technical resume and a creative portfolio, reflecting my expertise as a QA Engineer & Software Developer, as well as a Multimedia Specialist & Creative Director.

Built as a single-page application using pure HTML, CSS, and JavaScript with zero build steps, it features a custom dark premium theme, a dynamic state system for view and language switching (English/French), and smooth micro-interactions.

**Key Features:**
- **Dual Views:** Seamlessly toggle between "Tech" and "Creative" modes, which dynamically reorders sections and tailors the content/styling.
- **Bilingual:** Full English and French language support without reloading the page.
- **Zero Dependencies:** Pure vanilla HTML/CSS/JS, hosted directly on GitHub Pages.
- **Interactive Elements:** Features a custom video modal, scroll-spy navigation, skill bar animations, and a "Director's Cut" mini-game.

[🌐 Visit the live portfolio here](https://mohamadali2023.github.io/E-Portfolio/)

# Mohamad Ali - E-Portfolio Personnel

Ce dépôt contient le code source de mon e-portfolio personnel à double identité. Il sert à la fois de CV technique et de portfolio créatif, reflétant mon expertise en tant qu'Ingénieur QA & Développeur Logiciel, ainsi que Spécialiste Multimédia & Directeur Créatif.

Construit comme une application "single-page" utilisant uniquement HTML, CSS et JavaScript sans aucune étape de build, il propose un thème sombre premium personnalisé, un système d'état dynamique pour le changement de vue et de langue (Anglais/Français), et des micro-interactions fluides.

**Fonctionnalités Principales :**
- **Double Vue :** Basculez facilement entre les modes "Tech" et "Créatif", ce qui réorganise dynamiquement les sections et adapte le contenu et le style.
- **Bilingue :** Support complet de l'anglais et du français sans rechargement de la page.
- **Zéro Dépendance :** HTML/CSS/JS pur ("vanilla"), hébergé directement sur GitHub Pages.
- **Éléments Interactifs :** Comprend une modale vidéo personnalisée, une navigation "scroll-spy", des animations de barres de compétences et un mini-jeu "Director's Cut".

[🌐 Visitez le portfolio en ligne ici](https://mohamadali2023.github.io/E-Portfolio/)
